# ft_printf

## 📚 Description
**ft_printf** is a recreation of the standard C `printf()` function.  
The goal of this project is to implement formatted output handling using variadic functions while respecting the restrictions of the 42 curriculum.  
This version supports a selected subset of conversions and writes the result to the standard output.

```c
